# 🔧 Arduino UNO Projects

A collection of **20 hands-on Arduino UNO projects** built while learning and practicing Arduino programming, sensors, input/output devices, PWM, automation, and basic embedded systems.

## 📚 Projects

| # | Project | Main Concepts |
|---|---|---|
| 01 | 🔘 Pushbutton | Digital Input, `digitalRead()` |
| 02 | 💡 Pushbutton + LED | Digital I/O, `INPUT_PULLUP` |
| 03 | 💡 LED PWM | PWM, `analogWrite()` |
| 04 | 🔌 Relay | Relay Control, Button State |
| 05 | 🌞 Light Dependent Resistor | Analog Input, LDR |
| 06 | 💡 LDR Light Intensity Control | LDR, PWM, `map()` |
| 07 | 🌞🌙 LDR Day/Night | Sensor Thresholds, Conditions |
| 08 | 🎛️ Potentiometer Analog | Analog Input, ADC |
| 09 | 🎛️ Potentiometer Different Range | `map()`, Value Classification |
| 10 | 🚨 Infrared Buzzer | IR Sensor, Digital Input, Buzzer |
| 11 | 🚪 Infrared Door Counter | IR Detection, Counter, State Change |
| 12 | 📡 Infrared Sensor Digital | Digital Sensor Reading |
| 13 | 🌡️ DHT11 Sensor | Temperature & Humidity |
| 14 | ⚙️ Servo Motor | Servo Control |
| 15 | 🎛️ Servo + Potentiometer | Analog Input, Servo Control |
| 16 | 🚨 Ultrasonic + Buzzer + LED | Distance Detection, Outputs |
| 17 | 📏 Ultrasonic Sensor | Distance Measurement |
| 18 | ⚙️ Ultrasonic + Servo Motor | Distance-Based Servo Control |
| 19 | 🔢 7-Segment Display | Digital Outputs, Display Control |
| 20 | 🔢 7-Segment + Pushbutton | Display & Button Interaction |
